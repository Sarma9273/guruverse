# 🌍 Overview

Guruverse is a next-generation engineering portfolio designed to showcase projects, research, software architecture, artificial intelligence, cybersecurity, and technical expertise through a modern, modular and scalable experience.

Unlike traditional portfolios that simply list projects, Guruverse is designed as an evolving engineering platform where every feature is treated as an independent module.

The project emphasizes:

- Software Architecture
- Artificial Intelligence
- Cybersecurity
- Research
- Software Engineering
- User Experience
- Maintainability
- Scalability

# 🏗 Architecture

Guruverse follows a **Feature-Based Architecture**.

```
Pages
      │
      ▼
Layouts
      │
      ▼
Home
      │
      ▼
Features
      │
      ├── Hero
      ├── About
      ├── Timeline
      ├── Research
      ├── Experience
      ├── Projects
      ├── Contact
      └── Footer
```

Every feature owns:

- Components
- Styles
- Data

This architecture improves:

- Maintainability
- Scalability
- Reusability
- Readability

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Sarma9273/guruverse.git
```

Navigate into the project

```bash
cd guruverse
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
